## 首轮失败与修正记录

`independent-r1`、`independent-r2` 的失败报告保留，均为 13/14。前者验收器丢弃了单对象版本分页的顶层 protocol，误要求每条记录重复字段；修正后每页严格核对协议/Profile，并核对行所属对象。后者误要求新协议责任投影返回 200，实际冻结边界要求明确拒绝未实现解释；现固定要求 409 / PROTOCOL_NOT_SUPPORTED，检查没有业务字段泄漏和 SQL/S3 变化，旧协议仍严格要求完整 200。两次修正均仅改验收器，未改生产实现或原始契约。

本轮审查中发现并由 Kimi 修复的生产问题保留在协调目录和早期诊断报告中，包括版本读标识、控制面 NULL 判定、叙述来源改绑与派生读取的协议连续性；最终源码经过统一重验。
