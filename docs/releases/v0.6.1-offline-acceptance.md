## 发布物与来源

每个离线包恰含 Runtime API、Worker、PostgreSQL 17＋pgvector、MinIO Server、MinIO Client 五类镜像，以及该提交的完整源码归档（`runtime-source.tar.gz`，含 `deploy/world-lab/` 与 `deploy/world-02/`）与部署文件。Runtime 两镜像由本次源码构建；第三方镜像使用 `deploy/offline-release/images.json` 中固定的平台 digest，与 v0.6.0 相同（本机镜像 ID 也相同）。第三方 wheel 复用本机此前下载、逐个按 `requirements.lock` 哈希核对过的文件（`requirements.lock` 自 v0.6.0 未变），项目 wheel 由该提交重新构建，两个架构的项目 wheel 与 Release 附件的 wheel 逐字节相同。部署版本文本在打包时渲染为 v0.6.1，每个部署文件都有内部哈希。

`SHA256SUMS`、两份架构 manifest 与顶层 `release-manifest.json` 随 Release 附件提供。验收脚本与原始报告留在本机，不入库；报告不含凭据、数据库内容或原始日志。本次交付不表示生产部署完成。
