# v0.4.0：Method 0.4 正式链、独立来源与治理工作台

本版汇总 v0.3.0 以来已合并的 Runtime 功能。发布版本号与 Method 契约版本分别管理，不自动升级历史对象的协议绑定。

## 新增能力

- **`tkos.method/0.4` 正式链**：CEO Agent 直接 issue／reframe／associate；Agreement 由每位被提名当事人对同一精确 revision 各自确认，全部到齐才转 formal；正式更新链；Battlefield ＋ Domain 双主责范围；M1B 多 PCO 候选与整组激活——责任 DRI 与 Mission Owner 各自按「责任」承诺，CEO 只能整组确认、不能代替任何人承诺。无执行或验收副作用。
- **`tkos.workspace/0.2` 独立来源**：无业务锚点的会议／文档／本人选定对话场景；来源身份与版本、更正与撤回、精确分享无遍历、默认私有与来源围栏、不可变 Context 快照并在读取时重查当前授权；Agent 自建 Context／run 与引用草稿；commit／retry／get 在撤权后不恢复正文与自由文本。
- **本机治理工作台**：有权本人的个人会话入口，全部人工白名单动作的 typed 表单，精确引用由已授权对象选择器派生并在提交前展示完整预览。同源 ＋ CSRF ＋ `no-store`，登录限流，浏览器不接触任何治理凭据。默认关闭。没有数据库任意编辑器，也没有 Agent 身份选择器。
- **工作台按目的分组与业务主线**：四组导航（处理核对与确认／查看业务与依据／理解本体与规则／管理来源与追溯）。新增「业务主线」四栏视图，选中任一卡片后其下游按该卡片的精确 revision 收窄。
- **Runtime 与部署加固**：治理连接池与 `DATABASE_URL_FILE` 等凭据文件读取；部署侧新增可验证备份（partial→mv、逐文件 SHA256）、`pg_stat_statements` 语句计数与 Docker secrets 凭据。

## 交付形式

Release 附件包含 `tkos_memory_service-0.4.0-py3-none-any.whl`、`tkos_memory_service-0.4.0.tar.gz`、amd64／arm64 两套完整离线包、`SHA256SUMS` 与发布清单。每套离线包恰含 Runtime API、Worker、PostgreSQL 17＋pgvector、MinIO Server、MinIO Client 五类镜像；Clark、Nginx、模型服务、凭据、数据库备份与业务数据不在包内。前端生产资源随 Python 包交付。GitHub 同时提供标签对应的仓库源码归档。

## 升级及边界

数据库迁移是追加式，当前迁移至 **0028**（`0026_workspace_sources_v02.sql`、`0027_method_v04.sql`、`0028_method_v04_contract_repin.sql`、`0028_workspace_v02_grant_repair.sql`；后两者编号重复但文件名不同，均保留）。使用新源码执行迁移前应备份并在隔离环境验证。发布不自动迁移生产库，不升级旧 0.1／0.2／0.3 对象，不创建正式身份或授权。

治理工作台默认关闭，需显式设置 `TKOS_GOVERNANCE_WORKBENCH_ENABLED` 与账号文件；账号文件与令牌文件必须是本机私有权限（非 0o077），否则服务返回 `WORKBENCH_NOT_CONFIGURED`。

**尚未验证**：Clark 接线、Clark 浏览器端到端、真实业务模型、生产 SSO 与正式身份、远程部署与生产切换、M2 执行链。业务主线四栏的浏览器渲染尚未由人核对，其逻辑结论来自上表的接口级复演。源码预览与验收中的合成数据不随包发布。
