## 与 v0.5.0 离线验收的差异

- 新增 world 0.2 的控制面安装与整条链 HTTP 冒烟、镜像内 0.2 材料对锁版钉定哈希的核对，以及 v0.5.0 → v0.6.0 的升级检查（含 0039 之后 0.1 数据按 0.1 读、新 scope 启用 0.2）。
- 迁移头从 0038 到 0039（`0039_world_v02.sql`，2026-09-30 锁版冻结）；表数与 FORCE RLS 表数不变（80／51）。
- 与 v0.5.0 一样，**没有重跑** v0.3.0 的业务／看板 58 项与本体 HTTP/SQL 46 项矩阵。协议层面的独立验收沿用各自最近一次运行，本轮未重跑，见[发布说明](v0.6.0.md)的「验证依据」。

## 发布物与来源

每个离线包恰含 Runtime API、Worker、PostgreSQL 17＋pgvector、MinIO Server、MinIO Client 五类镜像，以及该提交的完整源码归档（`runtime-source.tar.gz`，含 `deploy/world-lab/` 与 `deploy/world-02/`）与部署文件。Runtime 两镜像由本次源码构建；第三方镜像使用 `deploy/offline-release/images.json` 中固定的平台 digest，与 v0.5.0 相同。第三方 wheel 复用本机此前下载、逐个按 `requirements.lock` 哈希核对过的文件（`requirements.lock` 自 v0.5.0 未变），项目 wheel 由该提交重新构建，两个架构的项目 wheel 逐字节相同。部署版本文本在打包时渲染为 v0.6.0，每个部署文件都有内部哈希。

`SHA256SUMS`、两份架构 manifest 与顶层 `release-manifest.json` 随 Release 附件提供。验收脚本与原始报告留在本机，不入库；报告不含凭据、数据库内容或原始日志。本次交付不表示生产部署完成。
