# v0.2.1：完整双架构离线发布

v0.2.1 修正 v0.2.0 的交付范围。业务代码仅更新版本标识；M1A／M1B、Contract-A A1–A3、交付闭环和历史兼容语义保持不变。

## 发布产物

- `tkos-ontology-runtime-v0.2.1-linux-amd64.tar.gz`
- `tkos-ontology-runtime-v0.2.1-linux-arm64.tar.gz`
- `release-manifest-amd64.json` 与 `release-manifest-arm64.json`
- `README-v0.2.1.md` 与顶层 `SHA256SUMS`

两个架构包都恰好包含五类镜像：Runtime API、Runtime Worker、PostgreSQL 17＋pgvector、MinIO Server、MinIO Client。Clark 不在发布包中；宿主机 Nginx 也不是容器镜像。每个包另含固定源码快照、部署模板、镜像来源 digest、内部文件清单和 SHA256。

第三方镜像固定到平台级 digest：pgvector/PostgreSQL 17；MinIO Server `RELEASE.2025-04-22T22-12-26Z`；MinIO Client `RELEASE.2025-04-16T18-13-26Z`。平台级 digest 与多架构 index digest 同时写入 manifest，避免可变 tag 漂移。

## 验证与部署边界

发布前分别执行归档路径、内外层 SHA256、五镜像集合、镜像配置架构、OCI 源码标签、Compose 展开、数据库迁移／授权、pgvector 扩展、MinIO＋mc 互操作、API／Worker 健康与 Runtime 业务链验证。具体结果以 Release 附件中的架构 manifest 为准。

离线安装步骤见包内 `deploy/offline-release/README.md`。包不含任何真实 `.env`、密钥、数据库 dump 或业务对象，也不自动创建企业正式身份和授权。发布成功表示可交付的离线安装介质已完成验证，不表示远程生产机器已经部署或切流。
