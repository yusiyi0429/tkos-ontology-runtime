## 与 v0.4.0 离线验收的差异

- 新增 world 0.1 的控制面安装与 HTTP 冒烟、Worker 任务执行、镜像内控制面材料与非 root 运行的检查，以及 v0.4.0 → v0.5.0 的升级检查。
- 证据桶只剩一个：v0.5.0 删除了从未被读取的 `artifact` 桶（#39），所以不再有「两桶版本化」一项。
- 与 v0.4.0 一样，**没有重跑** v0.3.0 的业务／看板 58 项与本体 HTTP/SQL 46 项矩阵，它们固定在 Method 0.3／迁移 0025 基线上。协议层面的独立验收沿用各自最近一次运行：world 0.1 **248/248**（`d261eb9`）、Method 0.5 **27/27**、Method 0.4 **68/68**、v0.2 运行时 **20/20**（`a6d1efa`），本轮未重跑。

## 发布物与来源

每个离线包恰含 Runtime API、Worker、PostgreSQL 17＋pgvector、MinIO Server、MinIO Client 五类镜像，以及该提交的完整源码归档（`runtime-source.tar.gz`，含 `deploy/world-lab/`）与部署文件。Runtime 两镜像由本次源码构建；第三方镜像使用 `deploy/offline-release/images.json` 中固定的平台 digest，与 v0.4.0 相同。部署版本文本在打包时渲染为 v0.5.0，每个部署文件都有内部哈希。

`SHA256SUMS`、两份架构 manifest 与顶层 `release-manifest.json` 随 Release 附件提供。报告不含凭据、数据库内容或原始日志。本次交付不表示生产部署完成。
